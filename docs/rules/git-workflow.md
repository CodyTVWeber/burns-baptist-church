# Git workflow

- Work on `plan/initial-site` for the initial site (one PR with the plan).
- **Commit often** after green checkpoints. Message format:

  `plan/initial-site: 1. <change> 2. <change>`

- Commit only implement-related files.
- **Push** at end milestone or when asked. Do not force-push.
- **Do not** open a second PR for the same plan work — edit the existing PR body instead.
