# Stack

- **HTML / CSS / JS only.** No npm, no React, no Tailwind CLI, no bundler.
- **GitHub Pages** from repo root (`/`). Add `.nojekyll` at root.
- **Relative URLs** only (`css/site.css`, not `/css/site.css`) so project Pages work.
- Local serve: `python3 -m http.server 8080`.
- Lint JS: `node --check js/site.js`.
- Google Fonts via CDN is fine; do not vendor a font build pipeline.
